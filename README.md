## Необходимые инструменты

Python 3, Git, JupyterLab и библиотеки SymPy, NumPy, Matplotlib. Модули `fractions`, `decimal` и `math` входят в стандартную библиотеку Python.

Для этой лабораторной установка SageMath не требуется.

## Запуск

1. Откройте терминал в папке проекта.
2. Установите необходимые библиотеки:

   ```bash
   python -m pip install sympy numpy matplotlib jupyterlab
   ```

3. Запустите JupyterLab:

   ```bash
   python -m jupyterlab
   ```

4. В открывшемся интерфейсе выберите `lab01.ipynb` и ядро Python.
5. Перезапустите ядро и выполните все ячейки сверху вниз. Сохраните notebook вместе с результатами.

Также notebook можно открыть в VS Code с расширением Jupyter или в Google Colab.

## Содержание работы

1. Сравнение вычислений с `float`, `Fraction` и `Decimal` для выражений `1/3` и `1/7 + 2/7`. Для второго выражения точность Decimal составляет 40 значащих цифр.
2. Проверка равенства `0.1 + 0.2 = 0.3` обычным сравнением и с помощью `math.isclose`, объяснение погрешности.
3. Исследование функции `g(x) = x**4 - 5*x**2 + 4`: разложение на множители, точные корни, первая производная, неопределённый интеграл и значение при `x = sqrt(2)`.
4. Преобразование выражения SymPy в функцию NumPy через `lambdify` и построение графика на отрезке `[-3, 3]`.
5. Выделение корней красными точками, определение интервалов положительных и отрицательных значений, проверка знака подстановкой одной точки из каждого интервала.
6. Сравнение графиков с 401 и 21 точкой сетки.
7. Индивидуальное исследование функции по последней цифре студенческого билета: разложение на множители, корни, производная, интеграл, график и краткий вывод.
8. Итоговый вывод из 5–7 предложений о точных и приближённых вычислениях, символьных переменных, роли NumPy, графиков и Git.
